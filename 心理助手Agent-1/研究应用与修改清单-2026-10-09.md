# 文献研究应用与修改清单

完整学习资料：[全流程学习与实验指南](全流程学习与实验指南.md)。

软件代码均位于本目录下 `hrv_companion_agent`；本轮没有修改或刷写硬件固件。

下表中的 IEEE 全文、提取材料及个人硬件诊断记录仅保留在本机，不随公开仓库上传；公开仓库包含源码、学习指南与来源引用。

| 文件 | 修改/新增内容 | 原因 |
| --- | --- | --- |
| `core/label_store.py` | 保存独立唤醒度、愉悦度、窗口评分范围及采集日期；评分整数校验 | 情绪名称不能代替真实维度标签；支持隔日评估 |
| `backend/routes.py` | 标签接口新增两个 1–9 分字段，严格校验 | 与网页、训练契约一致 |
| `backend/web/index.html`、`app.js` | 新增评分控件、说明、提交与保存后清空 | 每个窗口重新评分，避免旧分数误用 |
| `models/experimental_arousal.py` | 新增个人低/高唤醒二分类训练与离线预测 | 适合单人实验；不自动替换现有正式模型 |
| 同上 | 训练日/最后测试日隔离，标准化仅用训练数据，PPG/GSR/fusion 对照及多数类基准 | 减少相邻窗口泄漏，评估融合是否有用 |
| 同上 | 数据摘要、不可覆盖输出、超范围与低分拒判、明确未校准分数 | 保留试验记录，避免夸大情绪确定性 |
| `algorithms/hrv_extractor.py` | 修正 Poincare 算法说明、PRV/HRV 和短窗口解释，移除仿真效果互证说法 | 算法计算、论文证据与真实效果分开 |
| `models/train_pad_model.py` | 修正 CCC、2:1 留出和传感器差异的说明 | CCC 不是分类准确率，压力脉搏论文不可直接迁移 |
| `tests/test_experimental_arousal.py` | 新增非法标签、中性排除、日期隔离、多参与者/重叠拒绝、标准化泄漏和预测限制测试；修复夹具类型错误 | 验证新实验契约 |
| `tests/test_web_multimodal.py` | 增强网页标签接口测试：非法评分拒绝，评分原样保存，情绪名不能覆盖分数 | 验证网页到存储完整链路 |
| `docs/research` | 保存 3 篇 IEEE 全文、提取文本、检索 JSON 和论文结果截图 | 使研究来源可复查 |
| 本目录的学习指南 | 新增公式、采集/标注/训练/评估步骤、来源和限制 | 可直接用于学习与安排实验 |
| `硬件开发/实验采集与波形质量说明.md` | 新增硬件采集用途、当前诊断事实与质量解释 | 明确原始波形与合格训练窗口的区别 |

研究应用优先级：先进行个人唤醒度实验，愉悦度保存后再研究；保留既有五分类路径供多人数据充分时使用。未添加未经真实数据验证的具体情绪规则，未宣称实现网页自动个人模型推测，也未导入 DEAP 原始数据。

验证：2026-10-09，`D:\python-3.13.9\python.exe run_tests.py`，381 项软件测试通过。人工测试数据仅验证代码，不是分类准确率证据。

下一步：本人在至少两个日期采集非重叠、合格、独立评分窗口；最后日期只做测试。训练/测试两侧各类至少 5 窗口仅是运行下限，结果需要报告有效率、样本量、任务与时间相关性。
