# 从 PPG、GSR 波形到情绪分类：学习与实验指南

更新：2026-10-09。适用项目：ESP32 + MAX30102 + GSR/ADS1115 + MPU6050。

## 1. 先明确我们要得到什么

本项目当前最可行的实验目标，是根据同一使用者的生理变化推测“低唤醒 / 高唤醒”。唤醒度是身体与主观感受的激活程度；高唤醒可能是兴奋、紧张或生气，低唤醒可能是放松或疲倦。它不直接等于焦虑或开心。

我们同时记录“愉悦度”，即负面到正面的主观感受。以后数据足够时，可以研究唤醒度与愉悦度两条轴，再结合本人表达解释情绪。现在新增的模型只训练唤醒度，愉悦度先保存，不声称已完成四象限分类。

一句话流程：**真实采集 → 检查连续性和佩戴 → 从波形识别脉搏 → 提取 PPG/GSR 特征 → 与本人静息基线比较 → 配对独立自评 → 隔日训练与验证 → 给出推测或不确定。**

本指南区分“已实现功能”“实验建议”“尚未验证的效果”。软件测试通过只能证明代码契约成立，不能证明情绪分类准确。

## 2. 各传感器实际上测到了什么

| 设备 | 直接记录的量 | 本项目用途 | 解释边界 |
| --- | --- | --- | --- |
| MAX30102 | 红光/红外光强随时间变化，原始 ADC 计数 | 心搏位置、脉搏间期及变化 | PPG 得到 PRV，不能直接称为 ECG 的 HRV；当前没有血氧准确性验证 |
| GSR + ADS1115 | 模块输出电压 V | 均值、变化速度、波动幅度 | 未标定为皮肤电导，不用 µS；不能预设电压升高必然表示焦虑 |
| MPU6050 | 加速度/角速度及运动判断 | 标记运动干扰 | 不是情绪标签；静置模块也不能覆盖所有手指接触变化 |
| ESP32/USB | 时间、包序号、会话、错误计数 | 同步、追踪重启和丢包 | 接收到数据不等于收到可分类数据 |

## 3. 一次采集怎样开始

1. 使用已能稳定传数据的 USB 连接。MAX30102 轻贴固定在指腹，遮挡强环境光，避免用力压。GSR 两电极贴稳，接触条件尽量一致。
2. 手臂和 MPU 放在支撑面上。保持坐姿，记录当天时间、睡眠、咖啡因、活动和佩戴变化。这些会影响生理信号。
3. 在软件中确认本次电极佩戴。现有校准要求先稳定 **120 秒**，之后获得一个完整约 **60 秒**的合格静息窗口。因此从确认接触到保存基线通常至少约 **3 分钟**，错误或运动会延长时间。
4. 只有自己确实平静时才保存静息基线。基线不是系统自动猜出来的“平静”。
5. 保存基线后再积累新的约 60 秒窗口；不能把基线本身又拿去充当分类训练样本。
6. 换模块、重新佩戴、设备重启或接触条件改变时，重新做本次基线。

原始波形显示器和正式软件是两个采集用途。一个看原始信号、导出 CSV，另一个保存合格窗口和自评；同一个串口同时只交给一个读取程序。诊断波形模式的数据不会自动变成软件中的已标注训练数据。

## 4. 看波形时要检查什么

PPG 原始曲线通常带很大的直流背景，小幅周期变化才是脉搏。显示去直流曲线有助观察，但曲线变漂亮并不证明逐拍间期正确。红光与红外的一致性可帮助检查光路，二者一起变化也可能是共同运动干扰。

GSR 中缓慢的漂移可能来自生理变化，也可能来自接触、汗液或电极稳定。突然跳变、接近电源轨、脱落后的异常值优先作为接触问题处理。滤波不能恢复已丢失、削顶或脱落的数据。

当前显示工具在 `硬件开发/esp32_firmware/experiment_wave_viewer.py`，可查看原始 PPG、去直流 PPG、红光、GSR 电压和运动，并下载 CSV。具体启动方式见硬件目录的 `实验波形显示说明.md`。

## 5. 第一步处理：时间和质量

已实现的统一入口是 `core/sensor_pipeline.py`。USB、BLE 与网页应遵守同一数据契约。

先核对设备/启动会话、片段、包序号和设备时间。重复包不重复计数；丢包、错误、重启或片段中断后重新积累窗口。不能把中断前后的间期拼成一串，也不能给缺失数据补零后当成真实观测。

当前约 60 秒窗口至少需要 55 秒连续心搏跨度和 30 个有效间期，GSR 也需完整连续覆盖。代码检查 PPG 质量、灌注幅度、采样率、运动、GSR 电压/连续性及快速波动。这些阈值是工程筛查参数，不是医疗标准，也不是论文证明过的情绪分界线。

质量通过表示“可继续做特征研究”；质量不通过仍可显示波形，但不得保存成合格分类样本。若有效率长期很低，应先统计具体拒绝原因，再用固定的开发记录验证调整方案，不能为增加样本量直接删除质量判断。

## 6. 第二步处理：从 PPG 找出每一拍

学习时按以下顺序理解：

1. 保留原始信号和原始时间，分开处理每个连续片段。
2. 去掉缓慢直流背景，抑制与脉搏无关的高频杂波。离线分析可试验约 0.5–4 Hz 的带通，但这只是起点，必须根据采样率、波形和真实搏动检查，不能直接作为本项目新增默认参数。
3. 找一致的搏动标志点，例如每拍的峰或上升沿。设置最小间隔避免同一拍被识别两次；振幅阈值随信号情况调整。
4. 对照原始曲线逐拍检查漏检、双检和接触跳变。发生中断时开始新片段。
5. 计算相邻标志点的时间差 `IBI_i = t_i - t_(i-1)`，单位毫秒。每个间期带唯一心搏身份，不能按数值去重——连续两拍相同间期完全可能是真实的。

正式软件接收固件的 `ibi_events`，再验证身份、范围和连续性。波形显示器的去直流/离线滤波只用于观察与研究，不会绕过这一验证。PPG 的峰位置还受血管与脉搏传导影响，所以以下变异性特征应称为 PRV 特征或 HRV 代理特征。

## 7. 第三步处理：把 60 秒波形变成几个数字

设合格窗口中有 `N` 个间期，记作 `IBI_1 … IBI_N`。

| 特征 | 算法 | 表达什么 |
| --- | --- | --- |
| 平均心率 `hr_bpm` | `60000 / mean(IBI)` | 每分钟平均搏动数 |
| SDNN `sdnn_ms` | 间期样本标准差，分母 `N-1` | 本窗口总体间期波动 |
| RMSSD `rmssd_ms` | `sqrt(mean((IBI_(i+1)-IBI_i)^2))` | 相邻间期的变化 |
| pNN50 `pnn50_pct` | 相邻差绝对值大于 50 ms 的比例 ×100 | 较大逐拍变化的占比 |

例如间期 `[800, 810, 790, 800] ms`：平均心率 75 BPM，SDNN 约 8.16 ms，RMSSD 约 14.14 ms，pNN50 为 0%。这只是计算教学例子，没有情绪标签。

60 秒中一次漏检就可能让 RMSSD 明显升高；这时“高变异”可能来自错误。当前个人实验模型不使用 LF/HF 或 VLF。短窗口频域结果不能直接当作可靠的交感/副交感活动，更不能由一个指标直接定情绪。

对 GSR 电压 `v_i`，当前提取：

| 特征 | 算法/单位 | 表达什么 |
| --- | --- | --- |
| `gsr_mean_v` | 电压均值，V | 本窗口电压水平 |
| `gsr_std_v` | 样本标准差，V | 波动幅度 |
| `gsr_slope_v_s` | 电压对时间的最小二乘直线斜率，V/s | 上升/下降趋势 |
| `gsr_step_rms_v` | `sqrt(mean((v_(i+1)-v_i)^2))`，V | 相邻采样跳动 |
| `gsr_range_v` | 最大值减最小值，V | 全窗口变化范围 |

这里没有宣称完成可靠的 SCL/SCR 分解；未标定电压上的波峰不应直接标成皮肤电导反应次数。GSR 极性和量程由当前模块决定，用个人数据学习关系比手写“电压越高越焦虑”更合适。

## 8. 第四步处理：与本人的静息比较

同一个人的当天基线比跨人固定阈值更适合这个实验。代码保存完整静息特征，并计算：

`relative = (current - baseline) / max(abs(baseline), floor)`

心率的分母下限为 1 BPM，RMSSD 为 5 ms，GSR 均值为 0.02 V，避免接近零时比值爆炸。当前模型使用心率、RMSSD 和 GSR 均值的相对基线特征。

例如基线心率 70、当前 84，则相对心率为 0.20。只能说较基线升高 20%，不能只凭这点宣称焦虑。

## 9. 第五步处理：提供真正的标签

模型不知道你“内心到底是什么情绪”。训练需要本人对**刚过去的 60 秒**做独立自评。

- 唤醒度：1 很低、5 中间、9 很高，表达激活程度。
- 愉悦度：1 很负面、5 中性、9 很正面，表达感受的正负。
- 原有五类情绪名称仍可保存，但不自动换算成上述分数。

这不是经过验证的完整 SAM 量表实现，只是借鉴 9 点自评方式的实验输入。不要看系统预测再填分数；不要为了“凑高低两类”填写与实际感受不符的标签。刺激视频只是一种诱发方式，影片类别不能代替你的实际评分。

网页新增两个评分控件，接口检查 1–9 整数。`core/label_store.py` 保存日期、会话、窗口时间、特征、基线、质量和 `self_report`。不允许标注模拟窗口、低质量窗口、与基线重叠或与前一标签重叠的窗口。

目前可以留空评分以兼容旧功能，但没有独立唤醒度分数的记录不会进入新模型；评分恰好 5 的中间状态也排除。新实验分界是 `<5` / `>5`，与部分论文的 `<5` / `>=5` 不完全相同，结果不可直接对比。

## 10. 第六步处理：安排有限的个人实验

建议做 2–3 个日期的小实验，每次控制在自己能舒适完成的时长，而不是无限排查硬件。先争取低、高唤醒各若干合格窗口，再决定是否值得扩展。

可以轮换安静休息、自己愿意观看的轻松/激活素材，或日常任务。不要用剧烈运动制造高唤醒标签，它会同时改变运动干扰和心率。任务顺序在不同日期交替，避免模型只学习“越到后面越激动”或接触随时间漂移。记录刺激/任务和顺序，恢复期也可记录真实感受。

每个有效 60 秒窗口结束后评分；评分动作引起运动时，等待新的连续窗口。至少间隔 60 秒再保存，网页也会阻止重叠标注。

新模型的运行最低量是：训练日期低/高各至少 5 个窗口，最后测试日期低/高也各至少 5 个，共至少 20 个。**这是让小实验可以运行的下限，不是统计可靠性的保证。** 同任务连续窗口仍可能相关；条件允许时增加独立任务块和日期，报告任务、日期、有效率与样本数。

如果一直收不到合格窗口，先结束这一轮并分析拒绝原因，不能用软件伪造间期或标签。当前目标允许简单模型与保守推测，但真实数据这一步不可省略。

## 11. 第七步处理：训练和隔日测试

新增 `models/experimental_arousal.py` 是独立命令行实验入口，不会自动替换正式情绪系统。

已实现：

1. 验证真实数据、独立标签、基线、完整特征及不重叠窗口。
2. 限定单个参与者；实际采集保持同一设备和佩戴方案。
3. 早期日期用于训练，最后日期只用于测试。
4. 标准化仅拟合训练日；模型是带类别平衡的逻辑回归。
5. 分别评估 PPG、GSR、融合特征，并给出只猜多数类的基准。
6. 融合模型在看测试结果前固定使用；不能挑测试分数最高的一组然后宣称独立验证成功。
7. 保存模型、评估报告、数据 SHA256、训练/测试日期和样本数；拒绝覆盖已有输出。

旧五分类研究入口仍保留，要求更多独立参与者与标签；一个人的数据不能支持跨用户五类识别结论。

### 训练命令

在 PowerShell 中进入包的父目录：

```powershell
Set-Location 'D:\大创心理助手\心理助手Agent-1\hrv_companion_agent(1)'
& 'D:\python-3.13.9\python.exe' -m hrv_companion_agent.models.experimental_arousal train `
  --data '你的已标注窗口.jsonl' `
  --output 'hrv_companion_agent\models\arousal-personal-v1.joblib' `
  --test-day '最后采集日期，例如2026-10-12'
```

日期示例必须替换为数据中实际存在的最后日期。数据文件使用网页标签保存产生的 JSONL（默认文件名 `multimodal_labels.jsonl`，目录由 `config.DATA_DIR` 配置）；每行一个窗口。一个文件仅放本人的合格数据。历史未填写评分的行会被排除；模拟或旧格式行会被拒绝，不能修改标志把它们伪装成真实记录。

依赖为 numpy、scikit-learn、joblib，见 `requirements-optional.txt`。模型需真实数据，不能拿软件测试中的人工夹具作为训练效果。

### 预测命令

```powershell
& 'D:\python-3.13.9\python.exe' -m hrv_companion_agent.models.experimental_arousal predict `
  --model 'hrv_companion_agent\models\arousal-personal-v1.joblib' `
  --window '一个合格窗口.json'
```

`window.json` 是一个完整窗口记录，不是原始 CSV 或只有心率的 JSON。当前入口沿用窗口校验契约，需包含既有独立标签元数据；它不把标签用作预测特征。新唤醒度评分可以省略。此入口用于离线实验验证；尚未接入网页自动推测。仅加载自己生成的可信 joblib 文件。

## 12. 第八步处理：怎样解释评估与预测

| 指标 | 如何理解 |
| --- | --- |
| balanced accuracy | 各类别召回率的平均值，二分类中多数类策略常为 0.5 |
| macro F1 | 分别看两类的精确率与召回率，再平均 |
| confusion matrix | 行是真实低/高唤醒，列是预测低/高唤醒 |
| coverage | 模型分数达到 0.65 的测试窗口占比 |
| accepted accuracy | 只在这些接受窗口上的准确率；必须与 coverage 一起看 |

0.65 是探索性拒判阈值，模型分数没有概率校准，不能解释为“你有 65% 概率焦虑”。特征偏离训练范围或分数不足时返回不确定；符合条件时只输出低/高唤醒推测。预测与自评不一致，先检查信号与实验条件，不修改真实标签来配合模型。

第一次看过测试日结果后，它就成为已知结果；若据此改模型或阈值，需要新的测试日期。报告应写“同一参与者在留出日期上的实验结果”，不能写成普遍用户准确率或医疗结论。

DEAP 原论文的外围生理模态平均 F1：唤醒度约 0.533，愉悦度约 0.608；它包含比本项目更多的外围通道，不能等同 PPG+GSR 的效果。2023 论文表格报告随机森林/AdaBoost 的愉悦度 accuracy 约 0.76/0.77，唤醒度约 0.61/0.61。划分、特征、采集条件不同，不能直接拿来当本项目准确率。该论文的四象限文字存在不一致，项目保留明确的唤醒/愉悦轴，不照搬情绪命名。

IEEE Xplore 是论文检索与全文平台；DEAP 是其中论文介绍的独立数据集。读取 IEEE 全文不等于已获取 DEAP 原始数据。本次未用 DEAP 数据训练项目，也未把公开数据模型直接移植到个人设备。
