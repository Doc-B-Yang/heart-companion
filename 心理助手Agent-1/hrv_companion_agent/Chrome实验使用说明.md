# Chrome 实验使用说明

1. 每次电脑重启后，双击本目录的“启动实验服务.cmd”。它启动本机 API（8000）和被动 USB 波形服务（8011），已经运行的服务不会重复启动。
2. 打开 https://doc-b-yang.github.io/heart-companion/ 。Chrome 若询问本地网络访问，允许这个网站访问本机服务；也可在地址栏左侧的网站设置中调整。分析后端地址为 http://127.0.0.1:8000，波形服务为 http://127.0.0.1:8011。
3. 蓝牙选取 HeartCompanion 后，新版正式固件同时提供 PPG 与 GSR 波形。USB 与蓝牙可同时工作；USB 服务不再替换固件、也不再在 10 分钟后退出。不要同时用串口监视器占用 ESP32 的 USB 串口。USB 串口断开后服务会等待重连。
4. MAX30102 和 GSR 贴稳、手臂和 MPU 静置后，点击“已佩戴好电极”。按钮可以点击，但服务器仍要求新鲜真实数据才能确认此次佩戴。保持静息约 3 分钟；只有合格窗口才允许保存基线。
5. 自评文字、唤醒度和愉悦度可独立保存，不要求波形质量合格。后端离线时，输入保留并显示连接问题；恢复后再点击保存。自评保存不等于已创建合格的分类训练样本。

PPG 图显示实际红外 ADC 的 25 Hz 显示采样，并在浏览器去直流；心搏分析仍使用完整传感器采样。USB CSV 保存显示采样，BLE 下载保存接收的数据包。这些文件不能当作完整 100 Hz 原始数据。断段和时间缺口不连线，历史波形不表示正在采集。

信号质量不足时仍能观察、下载真实波形；界面不因此宣称已经准确识别情绪。GSR 当前记录模块输出电压，尚非经过电导校准的数值。数据只保存本机，不发布到 GitHub。
