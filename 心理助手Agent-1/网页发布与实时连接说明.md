# 网页发布与实时连接

仓库：https://github.com/Doc-B-Yang/heart-companion

网站：https://doc-b-yang.github.io/heart-companion/

## 网站与设备的关系

GitHub Pages 提供固定 HTTPS 地址，电脑关机后网站仍可打开。设备的 USB、原始波形服务与分析后端运行在你的电脑上；电脑关机或采集停止时没有实时信号。GitHub 不接收你的生理数据或聊天。网页不会自动启动、重刷或复位硬件。

## 第一次发布

1. 创建公开空仓库，把本项目推送到 main。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
3. Actions 中运行 Publish heart companion；成功后打开部署网址。
4. 后续改代码并推送 main，网站自动更新。

## 在网站显示真实波形

1. ESP32 接电脑；MAX30102/GSR 按实验要求佩戴，模块静置。先关闭占用串口的 IDE、网关及其他采集进程。
2. 打开 PowerShell，设置允许访问的**准确网页源**（不带仓库路径）：

```powershell
$env:WEB_ALLOWED_ORIGINS='https://doc-b-yang.github.io'
cd 'D:\大创心理助手\硬件开发\esp32_firmware'
python experiment_wave_viewer.py
```

现有服务使用 COM6，运行时最多采集 10 分钟并恢复生产固件。如串口已变化，先修改该脚本的 COM6 参数。它会初始化和标定传感器，应在准备佩戴、静置后启动。采集输出留在本机 diagnostics，已排除 Git 上传。

3. 在线页面展开“连接电脑端服务”，波形服务填 `http://127.0.0.1:8011`，保存并连接。
4. 如果浏览器询问本地网络访问，由你决定是否允许。Safari/Firefox 或部分浏览器版本可能不支持此连接；改用桌面 Chrome/Edge，或打开本机网页 `http://127.0.0.1:8011/`。
5. “真实信号接收中”才代表新鲜采样；“采集已结束 · 历史波形”只显示最后一段。下载 CSV 保存在电脑，网页去直流不修改原始数据。

## 分析与陪伴

在另一终端，同样设置 WEB_ALLOWED_ORIGINS 后：

```powershell
cd 'D:\大创心理助手\心理助手Agent-1\hrv_companion_agent'
python run_api.py
```

网站的分析后端填 `http://127.0.0.1:8000`。聊天、自评、基线和分类通过该后端执行。USB 原始波形试验与生产情绪分析是不同采集路径：波形不会自动转为分类特征。生产分析请在波形试验结束并恢复固件后，用网页 BLE 或硬件目录 gateway.py 接入，不要同时抢占 COM6。

API 和波形服务仅监听回环地址；不要转发端口或把未经身份验证的个人实验 API 暴露到公网。公开部署带身份验证的后端是后续独立工作。
